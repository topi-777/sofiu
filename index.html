Introducción

El video de Fazt Code explica qué es Supabase, una gran alternativa a Firebase. Muestra cómo crear una cuenta en la nube para tener una base de datos, usuarios y almacenamiento al instante.

El autor crea una tabla con productos (laptop, monitor y mouse) y demuestra cómo la plataforma genera una REST API automáticamente. También explica cómo probarla con Postman y la importancia de proteger los datos con seguridad RLS.

Conceptos Fundamentales

1. Supabase

Plataforma en la nube que ofrece backend completo (base de datos, usuarios y archivos), ideal como alternativa a Firebase.

2. PostgreSQL

Base de datos relacional basada en SQL que organiza la información en tablas con filas y columnas.

3. REST API Automática

Enlaces que se crean solos por cada tabla para consultar, agregar o borrar datos mediante peticiones web.

4. API Key

Clave de seguridad obligatoria (enviada en las cabeceras) que permite que las aplicaciones consulten la API.

5. RLS (Row Level Security)

Reglas de seguridad para controlar exactamente qué usuarios pueden leer o modificar los datos de las tablas.

Cuestionario Resuelto

1. ¿Cuál es el tema principal del video? Explica de qué trata.

Trata sobre Supabase y su funcionamiento básico. Muestra cómo crear una base de datos en pocos minutos, generar una API automática y proteger los datos con reglas de seguridad.

2. ¿Qué problema o necesidad tecnológica se aborda?

Evita tener que programar un backend desde cero. Además, soluciona el problema de seguridad al evitar que cualquier persona externa robe o altere los datos públicos.

3. ¿Cuáles son los cinco conceptos más importantes? Define cada uno.

1. Supabase: Backend rápido en la nube.
2. PostgreSQL: Base de datos en formato de tablas.
3. REST API: Conexión automática para leer y escribir datos.
4. API key: Contraseña pública para acceder a la API.
5. RLS: Filtros de seguridad para las filas de las tablas.

4. ¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

Se usan Supabase (para el backend), GitHub (para iniciar sesión), PostgreSQL (para las tablas), Postman (para probar las peticiones web) y bibliotecas para JavaScript.

5. ¿Qué procedimientos o pasos se explican? Preséntalos en orden.

Registrarse en Supabase con GitHub, crear un proyecto nuevo, crear una tabla de productos, cargar filas (laptop, monitor, mouse), copiar el enlace de la API, probarlo en Postman, activar la seguridad RLS y configurar políticas de lectura.

6. ¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

El ejemplo central es una tabla de productos. Al consultarla sin seguridad muestra los datos, pero al activar RLS sin reglas, la respuesta sale vacía, demostrando cómo actúan los permisos.

7. ¿Qué conocimientos previos son necesarios para comprender lo explicado?

Saber qué es una base de datos, entender cómo funcionan las peticiones web (API REST y formato JSON) y tener nociones básicas de herramientas como Postman.

8. ¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

Ahorra tiempo de programación, crea APIs de forma automática, usa bases de datos potentes y ofrece un plan gratuito excelente para prácticas.

9. ¿Qué dificultades, errores o precauciones deben considerarse?

Cuidado con exponer las claves públicas y recordar que si activas RLS sin crear políticas, la app no mostrará ningún dato (devuelve una lista vacía).

10. ¿Cómo aplicarías lo aprendido en un proyecto informático real?

Lo usaría para guardar datos en sistemas escolares o de inventario, conectando una página web con Supabase y configurando reglas de seguridad para que solo usuarios autorizados puedan modificar la información.

11. ¿Qué parte del video consideras más importante y por qué?

La parte de seguridad con RLS, porque enseña que una página funcione no significa que sea segura; hay que controlar bien quién accede a los datos.

12. ¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

Aprendí a conectar una web a una base de datos en la nube sin programar servidores. A otros se lo explicaría como una herramienta que te da direcciones web listas para consultar tus datos con total seguridad.
